# نموذج واجهة مصرفية تجريبي غير رسمي

هذا المشروع **تصوّر واجهة فقط**؛ لا يتبع مصرفًا ولا يتصل بأنظمة مالية ولا ينفّذ تحويلات أو مدفوعات. استخدم بيانات اصطناعية في العروض، ولا تُدخل كلمات مرور أو أرقام حسابات أو بيانات شخصية حقيقية.

## المتطلبات

- Node.js `>=20.19.0`
- npm 10 أو أحدث

## التثبيت والتشغيل

```bash
npm ci
npm run dev
```

## الفحص والبناء

```bash
npm run typecheck
npm run build
npm run check
npm audit
```

لمعاينة نسخة الإنتاج محليًا:

```bash
npm run build
npm run preview
```

## البيانات والخصوصية

- تُحفظ أسماء المستفيدين التجريبيين وتفضيل المظهر في `localStorage` على هذا الجهاز فقط.
- لا تُحفظ رموز سيناريو الاختبار. الرمزان `DEMO-SUCCESS` و`DEMO-FAIL` مخصّصان لاختبار واجهة العرض، وليسا كلمات مرور.
- لا توجد واجهة خلفية أو تكامل مصرفي. نجاح/فشل سيناريو الاختبار لا يدل على معاملة حقيقية.
- تطبيق الويب (PWA) يُسجّل عامل الخدمة في نسخة الإنتاج فقط. يحتاج التثبيت عادةً إلى `localhost` أو استضافة عبر HTTPS.

## النشر

انشر محتويات مجلد `dist/` على استضافة ملفات ثابتة تدعم HTTPS. إذا نُشر المشروع تحت مسار فرعي، فتحقق من نطاق عامل الخدمة (`sw.js`) ورابط البيان `manifest.webmanifest` في المتصفح المستهدف.
